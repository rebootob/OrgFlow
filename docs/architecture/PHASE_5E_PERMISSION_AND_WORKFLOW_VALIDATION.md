## 2. Shared Account Security Protocol (`GENERAL_SHARED`)

> [!CAUTION]
> **UNTRUSTED SHARED IDENTITY PROTOCOL:**
> `GENERAL_SHARED` เป็นบัญชี Kintone แบบใช้งานร่วมกันในเครื่องส่วนกลาง
> ระบบOrgFlow จะ **ไม่ให้สิทธิ์อนุมัติ (Approve), ตรวจสอบ (Review), หรือแก้ไข Workflow** แก่บัญชี `GENERAL_SHARED` โดยเด็ดขาด

- **View Rights:** ALLOWED (แผนผังองค์กร & สมุดโทรศัพท์พนักงาน)
- **Create Rights:** ALLOWED (สร้างคำร้อง DRAFT ใหม่ได้)
- **Edit / Approve / Review Rights:** **DENIED** (ต้องเข้าใช้งานด้วยบัญชีส่วนบุคคลของ Manager หรือ HR เท่านั้น)

## 3. Manager Without Kintone Account Resolution

สำหรับกรณีผู้บังคับบัญชา (Department Manager) มีตัวตนเป็นพนักงานใน App 53 แต่ **ไม่มีบัญชี Kintone ส่วนบุคคล**:
- **Recommended Option:** **Hybrid HR Proxy & Designated Kintone Group Approval**
- **Security Impact:** ปลอดภัยสูง (กระบวนการ Proxy ถูกบันทึกผู้ดำเนินการจริงใน Kintone Process History 100%)
- **Operational Impact:** ไม่ทำให้ Workflow ติดขัดเมื่อผู้จัดการไม่มีบัญชี Kintone
- **Audit Impact:** ตรวจสอบย้อนหลังได้ชัดเจนผ่าน Kintone Revision Engine
